# ПУЛЬС — сайт школы танцев

**Живой сайт:** https://w00nd1ch.github.io/pulse-dance/

Одностраничный сайт школы танцев в тёмной фиолетово-чёрной эстетике.
Чистые HTML, CSS и JavaScript — без сборки, зависимостей и сервера.

## Структура

```
index.html      разметка и контент
css/style.css   дизайн-система, адаптив, анимации
js/main.js      расписание, меню, валидация, счётчики
favicon.svg     иконка
```

## Как обновить сайт

Отредактируйте файлы и загрузите изменения в репозиторий (ветка `main`).
GitHub Pages пересоберёт сайт автоматически за 1–2 минуты.

## Локальный просмотр

Откройте `index.html` в браузере или запустите:

```powershell
python -m http.server 8000
```

## Контакты в макете

Телефон, адрес и цены — демонстрационные, меняются в `index.html`.
Форма заявки показывает успешную отправку, но пока никуда не пишет:
для реальных заявок нужно подключить Formspree, Netlify Forms или Telegram-бота.
